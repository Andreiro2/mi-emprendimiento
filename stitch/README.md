# Código exportado de Stitch

Código HTML de las 12 pantallas del prototipo (6 desktop y 6 mobile), exportado del proyecto de Stitch https://stitch.withgoogle.com/projects/17675665430477937727.

Es **solo referencia visual** para la etapa de código, como indica [`docs/10-spec-desarrollo.md`](../docs/10-spec-desarrollo.md). El sitio final se construye con HTML y CSS propios, sin Tailwind, siguiendo `DESIGN.md` y la spec de desarrollo.

| Pantalla | Desktop | Mobile |
|---|---|---|
| Landing | `landing-desktop.html` | `landing-mobile.html` |
| Tienda | `tienda-desktop.html` | `tienda-mobile.html` |
| Ficha de producto | `producto-desktop.html` | `producto-mobile.html` |
| Carrito | `carrito-desktop.html` | `carrito-mobile.html` |
| Blog | `blog-desktop.html` | `blog-mobile.html` |
| Artículo | `articulo-desktop.html` | `articulo-mobile.html` |
